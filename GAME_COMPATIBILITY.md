# CloudSSD game compatibility

No commercial-game acceptance is claimed. A compatibility scan is advisory. The app's Verified state requires a monitored run of at least 60 seconds without a failure signature; a short demo execution is not sufficient.

The demo workload exists only for reproducible filesystem/import/launch checks. Current results are in [TEST_REPORT.md](TEST_REPORT.md). See [application compatibility](COMPATIBILITY.md), [installation](GAME_INSTALLATION.md) and [limitations](KNOWN_LIMITATIONS.md).
