# CloudSSD compatibility

CloudSSD is cloud-backed file storage with local execution. It does not provide a remote Windows installation environment. Browsers/arbitrary application installers, services, updaters and commercial games need individual acceptance; none are guaranteed.

Hybrid requires symbolic-link privileges or Windows Developer Mode. Full Local uses a complete local footprint and normal launcher/ownership handling. Native VFS lacks some NTFS features, including alternate streams, hard links, ACL/EFS and reliable cross-process locking.

Read [current source verification](TEST_REPORT.md), [limitations](KNOWN_LIMITATIONS.md) and [game compatibility](GAME_COMPATIBILITY.md) for the exact boundaries.
